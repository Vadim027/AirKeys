# Виртуальная клавиатура

**Виртуальная клавиатура** — GUI-приложение, разработанное на языке программирования **C++** с использованием кроссплатформенного фреймворка **JUCE**.

Проект демонстрирует возможности виртуальной клавиатуры на примере ввода и редактирования текста в графическом интерфейсе приложения.
